# AS92005 Website Promotion Project Template

## Project Goal
Create a website that promotes a school extra-curricular activity.

Your website should:
- Inform users about the activity
- Encourage students to join
- Be easy to navigate
- Use appropriate images and media
- Follow website conventions
- Be fit for purpose

## Folder Structure

```text
as92005-website-template/
├── index.html
├── about.html
├── events.html
├── gallery.html
├── join.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
├── media/
└── docs/
```

## Files

### HTML Pages
- `index.html` = homepage
- `about.html` = information about the activity
- `events.html` = events, meetings, training, or practice times
- `gallery.html` = images or media
- `join.html` = how users can join or get involved
- `contact.html` = appropriate contact information

### CSS
- `css/style.css` controls the visual design of the website.

### Images
- Place your images in the `images` folder.
- Use appropriate file names, such as `rugby-training.jpg` rather than `IMG_1234.jpg`.
- Remember to use `alt` text for accessibility.

### Media
- Place video or audio files in the `media` folder if needed.

### Docs
- Use this folder for screenshots, notes, or evidence if your teacher asks you to.

## Student Checklist

Before submitting, check that:

- [ ] My website has at least 4 linked pages
- [ ] My navigation works on every page
- [ ] My CSS is linked correctly
- [ ] My images display correctly
- [ ] My text is readable
- [ ] My layout is consistent
- [ ] My website works on a smaller screen
- [ ] I have tested my website
- [ ] I have made improvements from testing or feedback

## Important Reminders

- Keep your file names lowercase and simple.
- Do not use spaces in file names. Use hyphens instead.
- Keep all CSS in the `css/style.css` file.
- Use copyright-free images or images you have permission to use.
- Do not publish private student contact details.
